# 诊断框架（判断标准）

本 skill 的判断标准，来自《稳定销售下滑诊断》。第 2–4 步都按这里的层级和规则判断，其他文件里的规则和这里冲突时，以这里为准。

## 核心原则

- 不是哪个指标差就改哪个指标，而是**找到第一个发生异常的变量**。不要用结果指标（订单、ACOS）找原因。
- **订单 = 流量 × CVR**。销量下降只有两个直接原因：流量减少，或转化率下降。
- 拆流量和转化之前，先判断是**市场整体**的问题，还是**链接自身**的问题。
- **广告最后才诊断**。广告动作只用来解决已经诊断清楚的问题。
- 常见误操作，不要这样建议：销量掉就加预算、ACOS 高就降竞价、排名掉就加广告。这样只会打乱广告结构，销量未必回升。

## 六层诊断顺序

报告按 ① → ⑥ 写，判断时也先看 ①，再往下。每层写一句结论：有没有异常、下一步往哪一层查。

### ① 市场需求：市场在跌，还是只有自己在跌？

| 维度 | 看什么 |
|---|---|
| 类目趋势 | 类目整体销量是否下降（细分市场看竞品或头部的大类排名） |
| 搜索需求 | 核心词搜索量是否下降（ABA 排名趋势） |
| 竞品表现 | 主要竞品的销量 / 排名是否同步下降 |

| 情况 | 判定 |
|---|---|
| 市场降 + 竞品降 + 自己降，降幅接近（差距 < 10 个百分点） | 偏生命周期 / 季节性 → 诊断结果 **A** |
| 市场稳 + 竞品稳或涨 + 自己降 | 链接竞争力下降，份额被抢 → 继续 ②–⑤ |
| 市场降，但自己降得明显更多 | 大盘 + 自身问题叠加 → A 之外继续 ②–⑤ |
| 市场降，自己稳或涨 | 跑赢大盘，不是市场问题 |

- 当天很难判断，以周、月为准；西柚的日数据只作参考。
- 市场萎缩时订单会更往头部集中（马太效应），越靠后的链接受影响越大。

### ② 销售拆解：流量掉了，还是转化掉了？

流量 = Sessions；整体 CVR = 总订单 ÷ Sessions。trend 脚本的"第②层"直接给出判定。

| 流量 | 整体 CVR | 判定 | 往哪查 |
|---|---|---|---|
| 降 | 稳 | 流量获取能力下降 | ③ 流量来源 → ④ 关键词权重 |
| 稳 | 降 | 同样的人进来，买的人少了 | ⑤ 相对竞争力 |
| 降 | 降 | 流量和竞争力双重恶化 | **先恢复转化（⑤），再恢复流量**，转化是第一优先级 |

销量下降 ≠ 广告下降，先定位掉在哪一层。

### ③ 流量来源：掉的是自然流量还是广告流量？

| 掉的是 | 看什么 |
|---|---|
| 自然流量 | 核心词自然排名、Top 10 / Top 20 关键词数量、自然关键词覆盖、核心词流量占比、自然订单占比 |
| 广告流量 | 曝光 / 点击、CPC / 预算 / 竞价、广告位、搜索词覆盖、高相关词流量占比 |

自然掉了 → 查 ④；广告掉了 → 查 ⑥（广告动作仍要等诊断结果定了再给）。

### ④ 关键词权重：自然排名下降只是现象，不是原因

| 原因 | 表现 |
|---|---|
| 关键词转化下降 | 该词 CVR ↓ → 订单密度 ↓ |
| 广告结构偏移 | 核心词流量 ↓、泛词 ↑（核心词是基本盘） |
| 相对竞争力下降 | 竞品促销、功能升级、Review 增长 |

链条：关键词权重 ↓ → 自然位 ↓ → 自然单 ↓。
**不要看到自然位下降就直接提高竞价。** 先问：这个词下面，我们为什么失去了持续拿订单的能力？

### ⑤ 相对竞争力：流量没掉，CVR 为什么下降？

| 维度 | 看什么（自己 vs 竞品） |
|---|---|
| 价格 | Price / Coupon / Promotion |
| 信任 | Rating / Review 的数量与质量 |
| 页面 | 主图 / 视频 / A+ / 卖点 |
| 产品 | 功能 / 材质 / 套装 / 差异化 |

转化是**相对竞争**：Listing 没变，不代表转化应该稳定。竞品降价、加 Coupon、Review 增长，都可能拉低你的 CVR。

### ⑥ 广告诊断（最后才做）

| 结构 | 异常信号 |
|---|---|
| 流量结构 | 核心词占比 ↓、泛词占比 ↑ |
| 订单结构 | 高相关词订单 ↓、低相关订单 ↑ |
| 成本结构 | CPC ↑、CPA ↑ |
| 位置 / 预算结构 | 首页顶部 / 其余位置 / 商品页的占比变化；预算是否错配 |

**危险信号**：广告订单稳定，但自然订单或自然排名在降、广告订单占比在升 → 广告在托住表面销量，链接拿自然流量的能力正在下降。trend 脚本会提示这个信号。

## 四种诊断结果

| 代号 | 诊断结果 | 核心表现 | 核心动作 |
|---|---|---|---|
| A | 市场生命周期 | 市场、竞品、自己同步下降 | 控成本、控库存、保利润 |
| B | 流量获取问题 | CVR 稳定，流量下降 | 恢复核心流量入口 |
| C | 转化竞争力问题 | 流量稳定，CVR 下降 | 先修价格 / 页面 / 产品竞争力 |
| D | 流量结构问题 | 广告占比 ↑，自然占比 ↓ | 重构关键词与预算结构 |

- 可以同时命中两个（比如 B + D），按影响大小分主次。
- D 的"流量结构"指广告订单和自然订单的占比，不是搜索词结构。广告订单占比没有上升、也没有危险信号时，不判 D。
- 一个都不命中，就写"未发现明确的下滑原因"，不要硬套。
- 流量和转化都降时，按 ② 的规则把 C 排在前面。

## 诊断结果 → 广告动作 → 验证

| 诊断结果 | 先确认什么 | 广告动作 | 主要验证指标 |
|---|---|---|---|
| B · 核心自然流量 ↓、CVR 稳 | 核心词的价值和趋势 | 筛出核心词 → 重点开精准（Exact） | 广告转化 + 核心词自然排名趋势 |
| B · 广告流量 ↓、CVR 稳 | 预算、CPC、广告位、搜索词 | 恢复高质量的付费流量 | 流量质量 + CPA |
| C · 流量稳、CVR ↓ | 搜索词效率、页面、竞品 | 保高效 → 收低效 → 修转化（价格 / 页面 / 产品先修） | CVR + CPA |
| D · 广告单稳、自然单 ↓ | 核心词趋势、广告订单从哪来 | 拆搜索词来源，把预算从泛词和商品页投放收回，给核心词 Exact | 核心词自然排名 + 自然订单占比 |
| A · 市场 / Session 整体 ↓ | 类目趋势、竞品、季节节点 | 控成本、保利润，不盲目硬加广告 | ROI、利润、库存节奏 |

关键词机会（拓词）是加流量的动作，也按诊断结果取舍：A、C 类只收割已验证的词（K1），不新增测试词；B、D 类优先核心词精准（K2）。详见 `keyword-opportunities.md` 6.6。

顺序：**先诊断 → 再匹配广告动作 → 最后验证**。每个动作都要写验证指标和复查日期（默认执行后第 7 天）。
